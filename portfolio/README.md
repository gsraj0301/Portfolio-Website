# Raj G — portfolio website

Personal portfolio: a "sticker board" of real projects, case studies, skills,
and hobbies (games, old PCs, writing, reading, chess). Built with Next.js (App Router) + Tailwind CSS, deployed on
Vercel.

- Live repo: https://github.com/gsraj0301/Portfolio-Website
- Docs at the repo root: `ARCHITECTURE.md`, `SPEC.md`, `DESIGN.md`,
  `CONTENT.md`, `CASE_STUDY.md`.

## Stack

- Next.js 14 (App Router), React 18, TypeScript
- Tailwind CSS v3 (design tokens in `app/globals.css` + `tailwind.config.js`)
- `@fontsource` fonts: Bricolage Grotesque, Figtree, Caveat
- `lucide-react` icons, `next/image` for all imagery
- Supabase (`@supabase/supabase-js`) for the contact form only
- CSS-only motion (hero slap, hover/press, games count-up, sticker wiggle), reduced-motion safe

Node 18 is the supported floor (Next 14 / Tailwind v3 are pinned for it).

## Getting started

```bash
npm install
cp .env.example .env   # then fill in the Supabase values (see below)
npm run dev            # http://localhost:3000
```

`.env` (gitignored):

```
NEXT_PUBLIC_SUPABASE_URL=https://<project-ref>.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=<publishable/anon key>
```

The anon/publishable key is safe in the browser. Never put a `service_role`
key in the frontend or in git.

## Scripts

- `npm run dev` — dev server (writes to `.next-dev`, so it never corrupts a
  production build)
- `npm run build` — `next build` **plus** `scripts/check-markers.mjs`, which
  fails the build if `[CHECK` or `[REPLACE` appears in the output
- `npm run start` — serve the production build
- `npm run lint` — ESLint
- `npm run verify:markers` — run the marker guard on its own

## Contact form backend (Supabase)

Run once in the Supabase SQL editor:

```sql
create table contacts (
  id bigint generated by default as identity primary key,
  name text not null,
  email text not null,
  message text not null,
  created_at timestamptz default now()
);
alter table contacts enable row level security;
create policy "anon can insert contacts"
  on contacts for insert to anon with check (true);
grant insert on public.contacts to anon;
```

Without the `grant`, inserts return 401 (new projects do not auto-grant).

## Deploy (Vercel)

1. Import the GitHub repo.
2. Add `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` in
   Project Settings → Environment Variables.
3. Deploy. All pages are statically prerendered.
